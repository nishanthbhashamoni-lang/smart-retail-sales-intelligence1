# Smart Retail Sales Intelligence

A retail data analysis project built using Python and NumPy to explore transaction data, calculate revenue, identify top-selling products, and compare sales across countries.

## Project Objectives

- Load and prepare retail transaction data.
- Apply NumPy arrays and Boolean indexing.
- Calculate transaction-level revenue using vectorized operations.
- Analyze sales using descriptive statistics.
- Identify top-selling products and high-revenue countries.
- Demonstrate 2D arrays, axes, and broadcasting.

## Technologies Used

- Python
- NumPy
- Python `csv` module
- Google Colab

## Dataset

Online Retail transaction dataset covering December 2010 to December 2011.

## Key Concepts

- NumPy arrays and array attributes
- Indexing and slicing
- Boolean masking
- Vectorized arithmetic
- Descriptive statistics
- Sorting and aggregation
- 2D arrays and broadcasting

## Important Note

Revenue is calculated as quantity multiplied by unit price. Revenue is not profit. The analysis focuses on selected positive-quantity, positive-price transactions; returns and cancellations require separate treatment.
